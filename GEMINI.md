## Project

**Project Context**

A UI overhaul and design system integration for a static frontend developer portfolio. The project transforms the existing standard UI into a playful, highly textured "Hand-Drawn" aesthetic.

**Core Value:** To create a memorable, uniquely styled portfolio that stands out through authentic texture, playful rotation, intentional messiness, and engaging interactive states (like buttons pressing flat).
