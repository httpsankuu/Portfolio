## ✨ Highlights & Architecture

- **🌓 Dynamic Theming:** Seamless Dark/Light mode toggle utilizing a scalable CSS custom properties architecture and persistent `localStorage` synchronization.
- **🌌 Interactive Canvas:** A lightweight, highly optimized 2D particle mesh (Constellation) in the hero section that reacts fluidly to cursor movement.
- **📈 GitHub REST API Integration:** Real-time fetching of GitHub statistics (language byte breakdowns, stars, followers, and top repositories), engineered with local caching to gracefully handle rate limits.
- **🛠️ Project Showcase:** Elegant visual cards featuring live demo links, repository access, dynamically rendered tech stack tags, and client-side metrics.
- **📜 Verified Credentials:** Embedded PDF viewing and one-click external verification for professional certifications.
- **📱 Responsive & Accessible:** Fluid mobile-first layouts, robust keyboard navigation (skip-to-content, focus trapping), and native `prefers-reduced-motion` support honoring user OS settings.

## ⚙️ Local Development

To run this project locally on your machine:

```bash
# 1. Clone the repository
git clone https://github.com/httpsankuu/Portfolio.git

# 2. Navigate to the project directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start the local development server
npm run dev

# 5. Build for production
npm run build
```
