# UI Design Contract — Phase 1

## 1. Design System & Brand

**Core Motif:**
Hand-Drawn, organic, and playful.
- No perfectly straight lines.
- Authentic texture (paper background).
- Playful rotation.
- Handwritten typography.

## 2. Typography Contract

| Role | Font Family | Weight | Size (Base) | Usage |
|------|-------------|--------|-------------|-------|
| Headings | Kalam | Bold (700) | 2rem+ | Section titles, prominent labels |
| Body | Patrick Hand | Regular (400) | 1rem | General text, paragraphs, buttons |

*Note: Both fonts should be imported from Google Fonts.*

## 3. Color Contract

| Token | Hex/RGB | Usage | Notes |
|-------|---------|-------|-------|
| Background | `#fdfbf7` | Global page background | Should incorporate a radial gradient to simulate paper texture |
| Text | `#2d2d2d` | Default body text | Very dark gray/off-black for organic contrast |
| Accent | `#ff4d4d` | Primary buttons, highlights | Playful, vibrant red |
| Shadow | `#2d2d2d` | Hard offset shadows | Used for elevated elements without blur |

## 4. Spacing & Layout (Not heavily modified in Phase 1)
- Continue using existing Tailwind utility classes for layout.
- The focus of Phase 1 is typography and global colors/background.
